`gulo-gulo-calendar-mail.png` is the resized project mascot artwork used by
the root README and reserved for future Gulo Gulo web splash, login, loading,
or other interface treatments. The source artwork is kept outside the
repository; this repository copy is 1200 × 1200 pixels and is intentionally
rendered at a smaller width in Markdown.

`gulo-gulo-favicon.png` is the master artwork for the browser tab favicon,
PWA manifest icons, apple-touch-icon, and the web header's brand mark. This
repository copy is the full-resolution 1254 × 1254 source; the actually
served, correctly sized derivatives (`favicon-32.png`, `favicon-192.png`,
`favicon-512.png`, `apple-touch-icon.png`, `brand-mark.png`) live under
[`web/icons/`](../web/icons/) and are regenerated from this file if it ever
changes, not committed as a resize of a resize.

The binary image cannot carry a text SPDX header, so this manifest records its
MIT attribution and ownership metadata. The complete license text is in the
repository root [`LICENSE`](../LICENSE).
